# Adiponectin EWAS
# Muhulo Muhau Mungamba
# 05_InSilico_Functional_Annotation

This folder contains scripts and documentation for in-silico functional
annotation analyses performed as part of the adiponectin EWAS.

## Contents

### R Scripts
- 05a_missMethyl_AADM.R  
  Gene set enrichment analysis using missMethyl for the AADM cohort

- 05b_missMethyl_RODAM.R  
  Gene set enrichment analysis using missMethyl for the RODAM cohort

- 05c_clusterProfiler_AADM.R  
  GO and KEGG pathway enrichment using clusterProfiler (AADM)

- 05d_clusterProfiler_RODAM.R  
  GO and KEGG pathway enrichment using clusterProfiler (RODAM)

- 05e_TF_enrichment_AADM_enrichR.R  
  Transcription factor enrichment analysis using enrichR (AADM)

- 05f_TF_enrichment_RODAM_enrichR.R  
  Transcription factor enrichment analysis using enrichR (RODAM)

### Documentation Files
- 05g_eQTM_AADM_documentation.txt  
  Description of methylation–expression (eQTM) analyses conducted in AADM

- 05h_iMETHYL_public_eQTM_documentation.txt  
  Documentation of public eQTM validation using the iMETHYL database

- 05i_eFORGE_documentation.txt  
  Documentation of chromatin state and regulatory feature enrichment using eFORGE

## Notes
- Analyses performed using web-based tools (eQTM via iMETHYL and eFORGE)
  are documented for transparency and reproducibility.
- All analyses are fully consistent with the statistical methods
  described in the manuscript and reviewer response letter.
